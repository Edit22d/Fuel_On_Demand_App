Requires Node ≥20; `npm run db:setup` runs `prisma generate && prisma db push && npm run db:seed` to provision schema and seed data. `npm run prisma:studio` opens the Prisma GUI. Development uses `nest start --watch`; production runs `node dist/main` inside the multi-stage Alpine image exposing port 8000. Environment variables are defined in `.env` and validated against `envValidationSchema` at startup.
